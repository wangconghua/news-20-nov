## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`render.py` (Python + PIL) draws the infographic; `main.ts` copies the
result into the output directory. No network calls, no randomness — the
output is byte-identical on every run.
